This project demonstrates multi-object tracking of polo players in aerial videos using YOLOv8. Each player rides a horse, so the model detects and tracks horses (COCO class 17) across frames using YOLOv8’s built-in tracker, assigning unique IDs to each player. The notebook Polo_tracking.ipynb allows uploading a video, performing detection and tracking, and saving the output video with bounding boxes and IDs. This project showcases practical multi-object tracking in sports videos and can be extended to other team sports or more complex tracking tasks.
